## Source units and hashes

`operations-waf-inventory.json` contains the exact trimmed Markdown control
cells as `{id, code, recommendation}`. `operations-advisor-inventory.json`
contains each section as `{id, title, content}`. Their hashes are generated by
`review_checklists.source_coverage.item_content_hash`, excluding retrieval
metadata. Each item retains its source URL; inventory metadata retains the
actual retrieval timestamp and page-reported revision.

Complete inventory means complete for the stated published **control-level
source unit**, not all WAF paragraphs, all Azure services or all Advisor
categories. Coverage is calculated from explicit mappings, with semantic scope
notes and matching item hashes. Source citation counts, canonical corpus counts
and unchanged import dates are not coverage denominators.

## Rejected and limited evidence

The guessed Front Door HTTP-to-HTTPS article URL returned 404. The actual
`front-door-url-redirect` article was fetched and used instead. This failure
and replacement are recorded in the manifest.

The published ARG table reference read in this pass did not establish the
inherited `CdnResources` custom-domain surface. The corresponding reversed
certificate-compliance query was removed, not relabeled as a validated
inventory. The queried configuration cannot prove certificate renewal.

The virtual-node overview contains an old claim about default kubenet
networking. That claim was deliberately not carried into the refreshed
recommendation. Advisor catalog entries also contain old retirement wording;
published presence is not certification of every service detail.

Inherited links and aliases were preserved for origin/compatibility. Unless a
URL appears in this pass's verified source inventory and the record cites it
as evidence, it was not automatically considered revisited. Most service
implementation pages and 203 exact baseline requirements remain explicit
manual-review work.
